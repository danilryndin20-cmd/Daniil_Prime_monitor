## Что здесь

Проект собирает персональный срез данных подписки ПРАЙМ из учебной базы PostgreSQL
(схема `prime`) по параметрам из `prime.assignments` и считает по нему восемь
агрегирующих показателей: масштаб участка, доли успешных/неуспешных событий,
раскладку по дням недели, самого активного участника, пиковые даты, скорость
накопления суммы внутри окна, устойчивость к «грязным» текстовым суммам
и поправку на день недели. Расчёты живут в `notebooks/hw1.ipynb`.

По мере курса раздел будет расти — сюда добавятся витрина клиента и метрики оттока.

## Как запустить

Нужны [Git](https://git-scm.com/) и [uv](https://docs.astral.sh/uv/).
Python отдельно ставить не нужно — его поставит uv.

```bash
git clone git@github.com:ВАШ_ЛОГИН/prime-monitor.git
cd prime-monitor
uv sync
```

Доступ к учебной базе выдаёт бот курса по команде `/db`. Полученную строку
подключения кладём в `.env`:

```bash
cp .env.example .env
# и вписать в .env строку из бота
```

Проверка, что всё встало:

```bash
uv run python -c "from prime.config import get_engine; print(get_engine().connect().execute(__import__('sqlalchemy').text('select current_user')).scalar())"
```

Запуск JupyterLab:

```bash
uv run jupyter lab
```
